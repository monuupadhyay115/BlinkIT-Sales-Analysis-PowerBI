# 🛒 BlinkIT Sales Analysis Dashboard | Power BI

An interactive Power BI dashboard designed to analyze grocery sales performance, compare product categories, and explore outlet performance across different business segments.

> **Portfolio project:** Data analysis • KPI reporting • Interactive dashboards • Business insights

---

## 📌 Project Overview

The objective of this project is to understand sales performance across product categories and outlet segments using an interactive Power BI dashboard. The report brings key performance indicators (KPIs) and visual comparisons into one place, helping users explore the data and identify patterns.

## 🎯 Project Objectives

- Summarize overall sales performance through key KPIs.
- Compare sales across item types and fat-content categories.
- Analyze performance across outlet location tiers and outlet sizes.
- Compare outlet types using multiple sales and product measures.
- Make the report easier to explore with interactive filters.

## 📂 Dataset Overview

The dataset used in this project contains **8,523 records and 12 columns**.

It includes information about:

- Item types
- Fat content
- Sales
- Ratings
- Outlet size
- Outlet location
- Outlet type
- Outlet establishment year
- Item visibility and related product/outlet attributes

## 🔍 Dashboard Features

### 1. Interactive Filters
Users can filter the report by:
- Outlet location type
- Outlet size
- Item type

These filters support focused comparisons between selected business segments.

### 2. Outlet Establishment Analysis
Shows how sales vary by outlet establishment year. In the current dashboard, the chart shows a peak around 2018, followed by lower sales in the later years displayed.

### 3. Fat Content Analysis
A donut chart compares Low Fat and Regular products to show their relative sales contribution.

### 4. Item Type Analysis
A horizontal bar chart compares categories such as Fruits and Vegetables, Snack Foods, Household, and Dairy, making it easier to compare category performance.

### 5. Fat Content by Outlet Location
Compares Low Fat and Regular product sales across Tier 1, Tier 2, and Tier 3 locations.

### 6. Outlet Size Analysis
A donut chart compares the contribution of Small, Medium, and High outlet-size categories.

### 7. Outlet Location Analysis
Compares sales across Tier 1, Tier 2, and Tier 3 locations. **Tier 3 shows the highest sales in this dashboard, at approximately 472,000.**

### 8. Outlet Type Comparison
A table compares Grocery Store and supermarket outlet types using:
- Total Sales
- Number of Items
- Average Sales
- Average Rating
- Average Item Visibility

## 💡 Key Insights

Based on the current dashboard:

- Total sales are approximately **1.20 million**.
- **Tier 3 outlets** show the highest sales among the three location tiers, at approximately **472,000**.
- **Fruits and Vegetables** and **Snack Foods** are among the leading product categories shown.
- **Supermarket Type 1** has the highest total sales among the outlet types displayed.
- The outlet establishment chart shows a peak around 2018, followed by a decline in the later years displayed.

These are descriptive observations from the dashboard. They do not establish the causes behind the patterns.

## 🖥️ How to View the Dashboard

1. Download or clone this repository.
2. Open `BlinkIT_Sales_Analysis_Dashboard.pbix` using **Power BI Desktop**.
3. Wait for the report to load.
4. Use the filter panel to explore sales by outlet location type, outlet size, and item type.
5. Review the KPI cards, charts, and outlet-type comparison table.
